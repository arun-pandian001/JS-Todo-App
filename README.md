# 📝 JavaScript Todo Application
A clean and functional Todo app built to demonstrate Vanilla JavaScript logic and interactive UI.

## 🚀 Live Demo
you can check out live version of this project here:[Todo-App live link](https://js-notes-app-wine.vercel.app/)
---

### 🛠 Tech Stack
- HTML5: Semantic structure.
- CSS3: Custom styling and layout.
- JavaScript (ES6+): Core logic, DOM manipulation, and task management.

### 🚀 Key Features
- Dynamic Updates: Tasks are added and removed in real-time without page refresh.
- DOM Mastery: Demonstrates efficient use of createElement and event listeners.
- Responsive: Works perfectly on mobile and desktop viewports.
